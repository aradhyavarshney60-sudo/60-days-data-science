# Day 60 — Final Reflection
## 60 Days of Data Science Challenge

### 1. Project Overview
The Customer Intelligence Platform is a customer churn analytics project built using Python, machine learning, FastAPI, and Streamlit.

### 2. Business Problem
Customer churn can affect business revenue and customer retention. This project explores churn patterns and provides predictions and recommendations to support customer-retention decisions.

### 3. Analytics Workflow
- Data preparation and cleaning
- Machine learning model training and evaluation
- Model comparison and explainability
- Customer churn prediction through FastAPI
- Interactive Streamlit prediction interface
- Business insights, recommendations, and documentation

### 4. Demonstrated Results
- Dataset: Telco Customer Churn
- Records: 7,043
- Model evaluation: Gradient Boosting achieved 80.62% test accuracy and 79.79% weighted F1 in the documented evaluation.
- API prediction endpoint returned HTTP 200 during local testing.
- Streamlit displayed churn predictions, probability estimates, risk levels, and recommendations.

These results describe the documented experiments and local tests; they do not guarantee production performance or business outcomes.

### 5. Key Learnings
- Building an end-to-end data science workflow
- Evaluating and explaining machine learning predictions
- Connecting a model to a FastAPI service
- Creating an interactive Streamlit interface
- Documenting testing, limitations, and business recommendations
- Using Git and GitHub to track project progress

### 6. Challenges and Improvements
Further work includes additional functional testing, deployment verification, input validation, model monitoring, and evaluation on representative unseen data.

### 7. Final Reflection
Completing this 60-day challenge helped me practice turning data science concepts into a documented, interactive project. It also reinforced the importance of testing, clear communication, and explaining model limitations.
